# PomLite

PomLite is a lightweight Python Pomodoro timer for improving focus and productivity.

## Features

- Pomodoro timer
- Short break
- Long break
- Session history
- Statistics
- JSON export

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```

Example

```
1. Start Pomodoro
2. View Statistics
3. Export
4. Settings
5. Exit
```
